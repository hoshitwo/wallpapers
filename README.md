# Answer

HTMLベースの便利ツールサイト

## フォルダ構成

```
Answer/
├── index.html          # メインページ
├── css/
│   └── style.css       # スタイルシート
├── js/
│   └── main.js         # メインJavaScript
├── assets/
│   ├── images/         # 画像ファイル
│   └── icons/          # アイコンファイル
└── README.md           # このファイル
```

## 開発方法

1. `index.html` をブラウザで開く
2. または VS Code の Live Server 拡張機能を使用

## 機能追加方法

- 新しいページ: `Answer/` 直下に `.html` ファイルを追加
- スタイル: `css/style.css` に追記、または新しいCSSファイルを作成
- JavaScript: `js/main.js` に追記、または新しいJSファイルを作成
- 画像: `assets/images/` に配置
- アイコン: `assets/icons/` に配置
